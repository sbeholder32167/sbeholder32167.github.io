    OIDC Template Code-Client 개선사항

    코드 개선 사항(2026-09-06)

    안녕하세요.

    코드 개선에 따른 변경사항을 알려드립니다.
    이용 시 참조하시기 바랍니다.
    변경 사항
    1. Discovery URI를 이용하여 OIDC 인증에 사용되는 각종 Endpoint를 읽어 동작하도록 개선된 Class를 제작하였습니다.
    • OIDCConfig Class 대신, KeycloakConfig, GoogleConfig, NaverConfig를 사용하실 수 있습니다.
    • 기존 OIDCConfig처럼 각종 Endpoint를 수동으로 입력한 Bean을 사용하셔도 무방합니다.
    • 사용 편의성 측면의 개선입니다.

    2. Naver 소셜 로그인 Provider를 작성하였습니다.
    • 이제 Naver 개발자 센터에서 Application을 등록하고 로그인을 하실 수 있습니다.
    • Google Provider를 적용할 때와 마찬가지로, OIDC Config, OIDC Provider, ClientAuthConvertAdapter 구현 Class만 바꾸면 인증이 동작합니다.
    • Google Provider와 마찬가지로, IDP 동시 로그아웃 기능은 지원되지 않습니다만 대신 발급받았던 토큰들을 취소하도록 구현하였습니다.
    추후 변경 예정 사항
    • Kakao Provider의 구현을 준비 중입니다.
    • Resource Server를 위한 Template Code를 구상중에 있습니다.

    감사합니다.
