    OIDC Template Code 기술 지원 / 컨설팅

    기술 지원 / 컨설팅 서비스를 제공합니다.

    Legacy Spring 또는 전자정부 프레임워크 애플리케이션과 최신 Keycloak(V26.x)을 연동하시는 데 어려움을 겪고 계신다면, 본 서비스가 도움이 되어드릴 수 있습니다.
    본 서비스는, 이미 동작이 확인된 Template Code를 적용하여 연동 개발 작업에 필요한 공수와 일정을 단축시켜 드리는 데 목적이 있습니다.

    제공하는 서비스는 아래와 같습니다.
    • 대상 애플리케이션 환경 분석
    • Legacy 세션 분석
    • OIDC Template Code 적용 가이드
    • Keycloak 연동 Trouble Shooting.
    1. 대상 애플리케이션 환경 분석
    연동 대상 애플리케이션 개발자와 함께 연동 대상 애플리케이션의 환경을 분석합니다.
    • 인증 데이터를 Keycloak에 연동하는 방식(JSON Import 또는 Keycloak User Storage SPI 구현)을 결정합니다.
    • 참고사항: 정확한 분석과 인증 쿼리 정형화를 위해 비즈니스 로직에 정통한 개발 담당자분의 긴밀한 협조를 부탁드립니다. (예상 소요 기간: 약 2일)
    • 안내: 면밀한 분석 결과, 구조적인 제약으로 인해 OIDC Template Code 연동이 어려울 것으로 판단될 경우, 신속히 공유드리고 협의하에 진행 여부를 결정합니다. (이 경우, 선행된 분석 단계까지의 공수 비용이 청구될 수 있는 점 양해 부탁드립니다.)
    2. Legacy 세션 분석
    연동 대상 애플리케이션의 세션 구조를 분석하여, 다음 단계인 OIDC Template Code 적용에 활용할 결과를 도출합니다.
    • 분석 내용: 코드 분석을 통한 정적 분석의 비율이 크지만, 디버깅을 통한 동적 분석도 필요합니다.
    • 참고사항: 세션은 비즈니스 로직과 밀접하게 연관되어 있어, 정확한 분석을 위해 개발 담당자분의 적극적인 참여가 필요합니다. (예상 소요 기간: 약 3일 / 일정 협의 가능)
    • 안내: 분석 결과에 따라 연동 진행 여부가 재검토될 수 있습니다. 중단 시 해당 단계까지 소요된 공수에 따른 비용이 청구될 수 있는 점 양해 부탁드립니다.
    • 위 작업일 (약 3일)은 세션 로직이 단순할 경우를 가정하고 산출된 일정임을 알려드립니다. (단순 사용자 속성 및 권한 정보만을 보유했을 때의 기준)
    3. OIDC Template Code 적용 가이드
    위 작업에서 파악된 세션의 구성 요소와 산출된 결과를 바탕으로 OIDC Template Code-Client를 커스터마이징하고, 연동 대상 애플리케이션에 적용하는 단계입니다.
    • 5종의 Customizing Interface 구현을 가이드하며, 특히 레거시 세션 변환을 담당하는 ClientAuthConvertAdapter 구현에 집중합니다. (예상 소요 기간: 약 1일)
    • 위 작업일 (약 1일)은 필수 Customizing 항목이자 가장 중요한 부분인 ClientAuthConvertAdapter 구현만을 가정하고 산출된 일정임을 알려드립니다.
    4. Keycloak 연동 Trouble Shooting
    OIDC Template Code-Client가 적용된 애플리케이션을 Keycloak 서버와 연동하며, 동작을 점검하고 문제점을 검토하고 해결하는 단계입니다.
    점검 대상 항목은 아래와 같습니다.
    • 로그인/로그아웃
    • 토큰 권한 매핑
    • 세션 중복 관리 기능
    연동 설정·클라이언트 적용 구간 중심의 가이드가 기본이며, 이슈 규모나 추가 수정 범위에 따라 투입 공수가 달라질 수 있습니다.
    (심화 원인 분석·추가 개발이 필요한 경우 별도 협의/공수 산정)
    [기타 유의 사항]
    • 진행 방식: 1, 2항의 분석 작업은 원활한 소통과 코드 리뷰를 위해 방문 서비스 또는 원격 회의로 진행됩니다. (방문 시 출장비가 별도 산정될 수 있습니다.)
    • 1과 2항의 분석 작업의 경우, 좀 더 상세한 분석과 정확한 결과 도출을 위해, 코드 리뷰 또는 동작 디버깅 등이 필요할 수 있습니다. 이런 경우 애플리케이션 개발자 분께 관련 요청을 드릴 수 있으니 양해 바랍니다.
    • 일정 유연성: 본 컨설팅은 연속 상주 형태가 아니며, 주 1~2회 등 고객사 일정에 맞춰 단계별로 유연하게 분할 수행이 가능합니다
    • 각 단계 산출물(분석 결과 공유, Template Code 적용 가이드 완료 등) 전달 시 해당 단계가 완료된 것으로 간주하며, 협의된 정산 조건에 따라 비용이 정산됩니다.
    • 지원 범위 한계: 4항의 트러블슈팅 단계는 OIDC Template Code-Client 연동 범위를 대상으로 합니다. Keycloak 서버 자체의 버그나 타 인프라 이슈는 지원 범위에서 제외되는 점 참고 부탁드립니다.
    • 기타: Keycloak의 FGA(Fine-Grained Authorization) 기능을 이용할 수 있는 'OIDC Template Code-Authz' 패키지는 별도 문의해 주시기 바랍니다.
    서비스 비용 및 세부 일정에 대해서는 메일로 문의해 주시면 상세히 안내해 드리겠습니다.
