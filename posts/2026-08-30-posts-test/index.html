    Github Pages를 오픈했습니다



    Github Pages도 처음이고, Jekyll도 처음이다 보니 엉성한 부분이 많습니다
    하지만 지금까지 누구나 쉽게 사용할수 있었던 채널들보다는 달리 새로운 방법을 이용하고 싶었습니다
    다른 사람들과 뭔가 차별점도 보이고 싶었습니다
    이렇게 작성하고 보니 용도 측면에서는 만족스럽습니다
    약간 까다롭다는 생각도 들지만 오히려 각 페이지에 대한 커스터마이징의 한계가 거의 없으니, 자유로움 측면에서는 포털 사이트 블로그들에 비해 압도적이라고 생각합니다


    추후 제 작품들에 대한 마일스톤이나 실험 내용을 공지하려면 여기가 가장 나을 것 같습니다.
    X에 비해서 한 페이지에 많이 게시할 수 있다는 장점이 있네요.
    하지만 댓글등을 이용한 소통 기능은 X가 더 낫다고 생각합니다.
    문의 사항은 좌측 패널의 X 또는 Email을 이용하여 주시기 바랍니다.
